
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python. Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador adivinhe letras para revelar uma palavra oculta antes de esgotar o número de tentativas permitidas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Atualizar o progresso quando o jogador acertar uma letra.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem informando se o jogador venceu ou perdeu.
